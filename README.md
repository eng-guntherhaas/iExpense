## iExpense

iExpense is a simple expense tracker app built using SwiftUI. It allows users to add and manage their personal and business expenses. The app saves expenses locally using `UserDefaults`.

### Features

- Add new expenses with name, type, and amount.
- Choose between 'Business' or 'Personal' expense types.
- List all expenses with a clear display of name, type, and amount.
- Remove expenses by swiping left on the list.
- Expenses are saved locally and persist across app launches.

### Usage

- **Adding an Expense:**
    1. Tap the `Add Expense` button in the toolbar.
    2. Fill in the expense details (name, type, amount).
    3. Tap `Save` to add the expense to the list.

- **Deleting an Expense:**
    - Swipe left on an expense item in the list and tap the `Delete` button.
